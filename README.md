# PropDesk marketing graphics

Campaign pack for [PropDesk](https://propdesk-beta.vercel.app/).

Two desks. Two audiences. Same blotter.

| Folder | Who it talks to |
|---|---|
| `traders/` | People about to buy an evaluation or instant book |
| `firms/` | Prop firms who pay to get listed |

Each audience has `x/`, `tiktok/`, and `youtube/`.

- **X** — landscape cards, 16:9 feel. Attach to the post.
- **TikTok** — 9:16 covers. First frame / pinned cover.
- **YouTube** — thumbs + channel banner. Series name: **Open Book Live**.

Brand lock: blotter `#231F19`, paper `#EFE6D4`, ink `#161310`. Serif headline. Ticket-P. No neon. No trophies. No "best firm." No other company logos as endorsement.

Paid listing is disclosed on firm creatives. Listing is coverage, not a rank.

The image files ship in `PropDesk-marketing-graphics.zip` from the build. Drop that zip onto this repo (or unzip into these folders) so GitHub holds the binaries.

## How to post

Read `CALENDAR.md`. Captions live next to each audience:

- `traders/CAPTIONS.md`
- `firms/CAPTIONS.md`

## YouTube series (traders)

**Open Book Live** — live trading by people who read the rule first.

Hook: the chart is open, the rule book is open, the size is last.

1. Live with the rule book open
2. They passed the eval. The funded account still died.
3. Stop. Read drawdown. Then size.
4. The homepage never said this.
5. Discord is not the source — we check the page on stream

Do not promise payouts. Do not crown a firm.
